4MBatteryTray

A lightweight open-source Windows system tray utility that monitors the battery percentage of the Microsoft Modern Mobile Mouse over Bluetooth Low Energy (BLE) using GATT Battery Service (0x180F) and Battery Level Characteristic (0x2A19).

Key Features

  • Dynamic Windows system tray icon showing current battery percentage and status details.
  • Configurable low battery alert threshold (10%, 15%, 20%, 25%) with +5% recovery hysteresis.
  • Configurable refresh intervals (1 min, 5 min, 15 min, 30 min) saved in %AppData%\4MBatteryTray\settings.json.
  • Optional startup entry via HKCU\Software\Microsoft\Windows\CurrentVersion\Run.
  • Distributed as a self-contained single-file .exe targeting net10.0-windows10.0.22621.0 (win-x64).
